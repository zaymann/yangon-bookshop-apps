# Yangon Book Shop Apps

Browser builds of **Yangon Photo Editor** (a fork of [PhotoCraft](https://github.com/storytold/photocraft))
and **Yangon Bookshop Pdfer** (a fork of [PdfCraft](https://github.com/storytold/pdfcraft)), served
with GitHub Pages. Everything runs in the visitor's browser; files are never uploaded.

- `photo-editor/`: `trunk build --release` of `apps/photocraft-web` (single-file wasm).
- `pdfer/`: `trunk build --release` of `apps/pdfcraft-web`.
