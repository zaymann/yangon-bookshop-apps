Yangon Bookshop Pdfer

PDF ဖတ်ခြင်း၊ ပြင်ခြင်း၊ ပေါင်းခြင်း၊ စာမျက်နှာ စီခြင်း။

သိထားရန်

  • ဖွင့်သော ဖိုင်များသည် သင့် device ပေါ်တွင်သာ ရှိပြီး မည်သည့် server သို့မျှ မပို့ပါ။
  • Save သို့မဟုတ် Export လုပ်လျှင် Downloads folder သို့ download အဖြစ် ရောက်ပါမည်။
  • Browser ကို ပိတ်ခြင်း သို့မဟုတ် reload မလုပ်မီ save လုပ်ပါ။
  • Chrome ၏ ⋮ menu › Add to Home screen ဖြင့် app တစ်ခုချင်းကို home screen တွင် ထည့်နိုင်သည်။
